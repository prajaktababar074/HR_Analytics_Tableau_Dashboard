
# HR Analytics Dashboard | Tableau

## Project Overview
This project focuses on analyzing Human Resources (HR) data using Tableau to understand employee attrition, workforce distribution, and employee satisfaction.

The interactive dashboard presents key HR metrics and visualizations to help identify workforce trends and support data-driven HR decisions.

## Objectives
- Analyze employee attrition patterns.
- Understand attrition across departments and education fields.
- Compare attrition by gender and age group.
- Analyze employee distribution across age groups.
- Explore job satisfaction ratings.
- Present key HR metrics through an interactive dashboard.

## Tools & Technologies
- Tableau Desktop
- Microsoft Excel
- Data Visualization
- Exploratory Data Analysis (EDA)
- HR Analytics

## Dashboard Features
- HR KPI Summary
- Department-wise Attrition
- Education Field-wise Attrition
- Attrition by Gender
- Attrition Rate by Gender and Age Group
- Employee Distribution by Age Group
- Job Satisfaction Rating

## How to Run
1. Download or clone this repository.
2. Open the Tableau workbook in Tableau Desktop.
3. Connect the workbook to the source Excel dataset if prompted.
4. Update the data source path if required.
5. Open the HR Analytics dashboard and explore the visualizations.

## Business Value
This dashboard helps HR teams explore employee attrition patterns, compare workforce segments, and monitor employee satisfaction to support better workforce planning.
